# 🧮 Basic Calculator (Python CLI)

A simple and interactive Command-Line Calculator built using Python. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division. This project helps beginners understand functions, input handling, and error management in a practical way.

---

## 🚀 Features

- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division (with division by zero handling)  
- ⚠️ Input validation using try-except  
- 🔄 Menu-driven interface  

---

## 🛠️ Tech Stack

- Python (Core Concepts)

---

## 📂 Project Structure

calculator.py   # Main program file

---

## ▶️ How to Run

1. Install Python  
2. Clone the repository:
   git clone https://github.com/BM804/Basic_calculator.git  
3. Navigate to the folder:
   cd calculator-cli  
4. Run the program:
   python calculator.py
